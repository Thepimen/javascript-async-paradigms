Paradigmas Asíncronos en JavaScript

Implementación comparativa de consumo de la API REST de JSONPlaceholder mediante Callback clásico (XMLHttpRequest), API Fetch con Promesas y Async / Await moderno.

Panel de Pruebas y Depuración

Abre las DevTools de tu navegador (F12 o Ctrl + Shift + I → Consola) para observar los registros formateados.

Caso 1

Callback Clásico

Petición asíncrona mediante el objeto nativo XMLHttpRequest implementando la firma estricta (url, callback) bajo la convención de manejo de errores Error-First.

XMLHttpRequest • Error-First Callback
Caso 2

Fetch con Promesas

Consumo mediante la moderna Fetch API nativa encadenando métodos .then() para resolución y desempaquetado de JSON, y .catch() para captura de errores.

fetch() • Promesas (.then / .catch)
Caso 3

Async / Await Moderno

Sintaxis síncrona declarativa sobre código asíncrono utilizando la palabra clave await dentro de una función async con estructura de control de excepciones try / catch.

async / await • try / catch
